# Line Color

Line Color improves readability in Odoo list views by highlighting duplicate product lines with configurable color groups.

## Features
- Detects duplicate product lines in list/tree views.
- Applies consistent color grouping for faster visual scanning.
- Configurable palette: background, border, and hover colors.
- Configurable document scope:
  - Sales Orders
  - Purchase Orders
  - Invoices
  - Delivery Orders / Receipts / Internal Transfers

## Configuration
1. Go to configuration menus for Line Colors.
2. Define and sequence colors.
3. Configure Line Color Scope for target document types.
4. Open a supported list view and duplicate lines to see colors applied.

## Technical Notes
- Uses web client list renderer patching to add row classes.
- Compatible module versions are provided for Odoo 16, 17, 18, and 19.
