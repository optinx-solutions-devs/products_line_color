What This Module Solves

Duplicate products in large documents are easy to miss in standard list views. Line Color applies deterministic row-group coloring so users can visually identify repeated products and validate data faster.

  • Better readability for long one2many line lists.
  • Faster spotting of repeated product lines.
  • Lower risk of quantity and pricing review mistakes.

Feature Highlights

  • Configurable palette: background, border, and hover color per group.
  • Configurable scope by document type.
  • Separate stock operation controls: Delivery, Receipt, Internal Transfer.
  • Stable color grouping for duplicate products inside each document.
  • Lightweight frontend behavior with backend-managed settings.

Quick Setup

Step 1: Install the module.
Step 2: Open Line Colors in configuration and define your palette entries.
Step 3: Open Line Color Scope and enable target documents.
Step 4: Create duplicate product lines in supported documents and verify automatic highlighting.

Compatibility

  • Odoo 19 Community and Enterprise.
  • Designed for backend list/tree rendering behavior in the web client.
