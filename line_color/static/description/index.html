How It Works (Output First)

First see the actual result in documents, then configure the palette and scope.

STEP 1 - RESULT

Delivery Lines Highlighted Automatically

Duplicate product lines in Delivery operations are grouped with color backgrounds for quick visual verification.

STEP 2 - RESULT

Invoice Lines Follow the Same Color Logic

The same duplicate-line detection can be applied to invoice lines when enabled in scope settings.

STEP 3 - NAVIGATION

Open Line Color Menus from Settings

The module exposes a dedicated Line Color menu in Settings so administrators can manage everything from one place.

STEP 4 - CONFIGURATION

Define Your Color Palette

Set sequence and color values (background, border, hover) to match your team preference and readability needs.

STEP 5 - CONFIGURATION

Control Scope by Document Type

Enable or disable coloring for Sales, Purchase, Invoice, and each inventory operation type independently.

Feature Highlights

  • Configurable palette: background, border, and hover color per group.
  • Configurable scope by document type.
  • Separate stock operation controls: Delivery, Receipt, Internal Transfer.
  • Stable color grouping for duplicate products inside each document.

Quick Setup

  1. Install the module.
  2. Open Line Colors and define your palette.
  3. Open Line Color Scope and enable target documents.
  4. Create duplicate product lines and verify highlighting.

Q: Does it work for both Community and Enterprise?

A: Yes, Odoo 19 Community and Enterprise are both supported.

Q: Can I enable colors only for Delivery and not Invoices?

A: Yes, the Scope configuration lets you enable each document type independently.

Q: Is this only for Sales Delivery?

A: No. It can be applied to Sales, Purchase, Invoice, Delivery, Receipt, and Internal Transfers based on scope settings.
