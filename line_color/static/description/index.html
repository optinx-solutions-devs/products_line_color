Step 1: Delivery output

Duplicate lines are color-grouped automatically in delivery operations.

Step 2: Invoice output

The same logic can be applied to invoice lines when scope is enabled.

Step 3: Menu access

Manage everything from Settings -> Line Color.

Step 4: Palette

Configure sequence and colors (background, border, hover).

Step 5: Scope

Enable only the document types where you want line coloring.

  • Deterministic duplicate-line color grouping.
  • Configurable palette and ordering.
  • Per-document scope controls.
  • Supports Sales, Purchase, Invoices, Delivery, Receipt, Internal Transfer.
