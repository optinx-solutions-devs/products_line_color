Line Color

Smart color grouping for duplicate product lines in Odoo list views

Why This Module?

In long sales, purchase, invoice, and inventory operation lists, duplicate products are hard to spot quickly. Line Color automatically highlights duplicate product lines with consistent group colors so users can scan, compare, and verify line items faster.

Key Features
  • Automatic duplicate product detection in list rows.
  • Color palette management with background, border, and hover colors.
  • Scope configuration by document type.
  • Supports Sales, Purchases, Invoices, Deliveries, Receipts, and Internal Transfers.
Configuration
  1. Open Inventory or Sales configuration and go to Line Colors.
  2. Define the color set and sequence order.
  3. Open Line Color Scope and enable the target documents.
  4. Use your normal workflow; duplicates are highlighted automatically.
